# Effects

Method and path: GET /api/v1/effects.

Area: Effects.

## Request

**GET /api/v1/effects**

Lists the effects and saved patterns in the library.

```sh
# Check who owns port 9430 first; see the Verify the listener before you send the token section of the getting-started page
curl -X GET -H "Authorization: Bearer $TOKEN" "http://127.0.0.1:9430/api/v1/effects"
```

```js
const response = await fetch("http://127.0.0.1:9430/api/v1/effects", {
  method: "GET",
  headers: {
    Authorization: `Bearer ${token}`,
  },
});
const data = await response.json();
```

## Types

**GET**

**Request body**: `none`.

No field list is published for this body.

**Answer body**: `EffectsResponse`.

| Field | Type | What it holds |
| --- | --- | --- |
| `effects` | `array of EffectSummary` | The effects in the library. |
| `active` | `string or null` | The id of the active effect, or null when none is active. |
| `failed` | `array of FailedEffect` | User effect files in the effects folder that did not load, with the reason why. |
